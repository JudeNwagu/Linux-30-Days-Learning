# 30 Days of Linux Learning

Welcome to my **30 Days of Linux Learning Challenge**.

This repository is where I document my Linux learning journey over 30 days, starting from the fundamentals and gradually moving into practical command-line usage, file systems, permissions, process management, networking, shell scripting, and system administration concepts.

The purpose of this challenge is to stay consistent, strengthen my practical Linux knowledge, and build the habit of documenting what I learn every day.

---

## Goal
The goal of this challenge is to:

- build consistency through daily learning
- improve practical Linux skills
- document progress in a structured way
- strengthen discipline through daily GitHub commits
- turn learning into hands-on understanding

---

## Final Outcome
At the end of this 30-day challenge, I aim to have:

- a strong understanding of Linux fundamentals and core system concepts
- hands-on practice with real Linux commands and workflows
- a practical Linux-based project
- improved consistency and learning discipline
- a documented learning journey I can always revisit
